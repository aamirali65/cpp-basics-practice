# CPP Basics Practice

Five small C++ console programs from my early practice with the language — the kind of exercises that build up variables, arithmetic, conditionals and basic input.

## Contents

| File | Exercise |
|---|---|
| `Arthematic.cpp` | Arithmetic operations on two numbers |
| `CalculateTotal.cpp` | Summing values into a running total |
| `FahrenheitCal.cpp` | Temperature conversion to Fahrenheit |
| `Quadric.cpp` | Solving a quadratic equation |
| `RadiusCalculate.cpp` | Circle area/radius calculation |

## Running a program

Each file is standalone. Compile and run one at a time:

```bash
g++ Arthematic.cpp -o arthematic
./arthematic
```

## Notes

Written as coursework practice rather than a library, so the programs print to `stdout` and take input from the console.
